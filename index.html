How I Started My Website

I started my webpage with the DOCTYPE declaration. The <...!DOCTYPE html...> tells the browser that my document uses HTML.

HTML

HTML is the language I used to create the structure of my webpage. HTML uses tags such as headings, paragraphs, lists, links, and images.

Headings

I used the <...h1> and <...h2> tags to create headings. Headings organize my webpage and make it easier for visitors to understand the different sections.

Paragraphs

I used the <...h1> and <...h2> tag to write information and explanations on my webpage. Paragraphs are used for normal text.

Lists

I used the <...ul> and tags to create an unordered list. An unordered list shows items with bullet points.

I used the < ol> and < /ol > tags to create an ordered list. An ordered list shows items with numbers.

I used the < li > and < /li > tags to create each item inside my lists. again my Easy way to remember are : < li > = starts a list item also < /li > = ends a list item, so ul = the whole bullet list and ol = the whole numbered list also li = one item inside the list . see my example here or you can look below and see by my examples : HTML tags, HTML attributes, CSS, Bootstrap, also I ask for help when I do not understnd, I ask deborah harding as my proffessor who teach me, I ask student to help me and they did good job

Links

I used the <...a> and href tags to create a link on my webpage. The a tag creates a clickable link.

I also used the href attribute. The href tells the browser which webpage the link should go to.

In my project, I created a "Learn More" link that takes the visitor to W3Schools. also remember that <...a...> = starts the link and also <..../a...> = ends the link, however href = tells the browser where the link should go and there is Learn More = the text the visitor clicks, in additional, class → gives it Bootstrap styling

Images

I used the <...img...> tag to add an image to my webpage. The img tag displays an image and does not need a closing tag.

I used the src attribute to tell the browser where my profile picture is located. My image is saved in my images folder.

I used the alt attribute to describe my profile picture. This is helpful for people who use screen readers.

I also used the Bootstrap class card-img-top to place my image at the top of my Card. For me to remember is that : alt → gives the image a description. also src → tells the browser where the image is located. also <....img....> → tells HTML to display an image. also class="card-img-top" → uses Bootstrap to style the image at the top of your Card. style="width:100%" → makes the image use the full width of the Card.

Bootstrap

Bootstrap is a framework that I used to help style and organize my webpage. It provides ready-made classes that I can add to my HTML instead of creating all the styles myself.

I added the Bootstrap stylesheet inside the head section of my HTML document. I found the Bootstrap information and examples on W3Schools and used them to learn how Bootstrap works.

I used Bootstrap classes such as container-fluid, row, col, card, btn, alert, and other classes in my webpage.

The Bootstrap stylesheet is connected to my webpage using the link tag. This allows the Bootstrap styles to work on my website.

Bootstrap Grid

I used the Bootstrap Grid to organize information into horizontal columns on my webpage. I used the <...div class="row"...> to create a row and <...div class="col"...> to create the columns inside the row.

The row holds the columns, and the col class makes the columns share the available space. I used this to organize my HTML, Headings, and Paragraphs information next to each other.

I also used Bootstrap classes such as p-3 for padding, bg-primary for the background color, and text-white to make the text white.
